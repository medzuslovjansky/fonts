# Interslavic Typography & Fonts Monorepo

Typography packages for Interslavic, modern Slavic languages, and Old Cyrillic typography.

## Packages

* [`@interslavic/slovosbor-serif`](packages/slovosbor-serif) — Slovosbor Serif variable webfont commissioned and funded by [Yaroslav Serhieiev](https://github.com/noomorph), designed and expanded by [S.-V. Sofienczuk-Wojczyszyn](https://www.fiverr.com/sergevictor) (derived from IBM Plex Serif by [Bold Monday](https://www.boldmonday.com/)). Features deep Cyrillic, Yat, Yus, and OpenType localization support.
